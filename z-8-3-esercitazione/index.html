Esercitazione 8.3: Fitting di modelli compartimentali e mappe metaboliche

Fonte: Fitting da modelli compartimentali e Esercitazione - diapo.pdf.

Queste diapositive accompagnano l’implementazione e il fitting di modelli bi-compartimentali e la costruzione di mappe metaboliche. Sono riportate come materiale di riferimento per l’esercitazione sulle mappe metaboliche da immagini dinamiche [18F]FDG-PET.

Punti principali¶

  1. Implementare il modello bi-compartimentale mediante la soluzione analitica bi-esponenziale.

  2. Estrarre una input function e una curva tissutale dal dataset clinico fornito e dalle ROI.

  3. Stimare il macro-parametro Ri con il metodo grafico di Patlak.

  4. Stimare i micro-parametri cinetici con fitting non lineare del modello compartimentale.

  5. Applicare il fitting a tutti i voxel di una sezione del volume per generare mappe parametriche.

Funzione da implementare¶

Nel file Scheletro Es 10b_AnalyticMethod.py va implementata la funzione:

La funzione prende in ingresso le quattro costanti del modello compartimentale e il vettore dei tempi, converte i parametri nel set di variabili ausiliarie e calcola CT(t).

Esempio di fitting non lineare¶

LSQfit_example.py¶

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
Esempio di fitting tra dati rumorosi e  modello non lineare

"""

import numpy as np
import matplotlib.pyplot as plt
from scipy.optimize import curve_fit

def non_linear_model(t, a1, b1, a2, b2):
    """Esempio di modello non lineare."""
    return a1 * np.exp(-b1 * t) + a2 * np.exp(-b2 * t)

# %%
# utilizzo della funzione curve_fit per il fitting di modelli non lineari
# a dati misurati

t = np.linspace(0, 2, 50)
p = [3, 10.5, 8, 1.4]
y_true = non_linear_model(t, *p)
np.random.seed(1)
ydata = y_true + 0.3 * np.random.randn(len(y_true))

plt.figure()
plt.plot(t, y_true, 'r-', t, ydata, 'b*')
plt.legend(['curva simulata', 'misura'])
# plt.show()


x0 = [1, 1, 1, 0]

# We run the solver and plot the resulting fit.
p_est, pcov = curve_fit(non_linear_model, t, ydata, p0=x0)
y_fit = non_linear_model(t, *p_est)

plt.plot(t, y_fit, '-k')
plt.legend(['curva simulata', 'misura', 'curva stimata'])
plt.show()

# %%
# aggiunta di opzioni (bounds)
lb = [0, 0, 0, 0]  
ub = [5, 15, 10, 3]

plt.figure()
plt.plot(t, y_true, 'r-', t, ydata, 'b*')
plt.legend(['curva simulata', 'misura'])

p1_est, pcov1 = curve_fit(non_linear_model, t, ydata, p0=x0, bounds=(lb, ub))
y_fit1 = non_linear_model(t, *p1_est)

plt.plot(t, y_fit1, '-k')
plt.legend(['curva simulata', 'misura', 'curva stimata'])
plt.show()

# %%
print(f"Valori dei parametri: {p}")
print(" PRIMO FITTING: ")
print(f"  Parametri: {p_est}, ResNorm: {np.sum((ydata - non_linear_model(t, *p_est))**2)}")
print(" SECONDO FITTING: ")
print(f"  Parametri: {p1_est}, ResNorm: {np.sum((ydata - non_linear_model(t, *p1_est))**2)}")
